# Automation & Workflow

Patterns and examples for automating repetitive technical work: containerization, task scheduling, API integration, and logging.

## Structure

- `docker/` — Example Dockerfiles and deployment patterns.
- `scheduling/` — Task automation examples (e.g. Windows Task Scheduler, cron).
- `apis/` — Patterns for integrating with and consuming APIs.
- `logging/` — Logging framework setups and best practices.

## Philosophy

Automation here is treated as a workflow-continuity problem, not just a scripting exercise — the goal is systems that are reliable, observable (via logging), and easy to hand off or reproduce.
